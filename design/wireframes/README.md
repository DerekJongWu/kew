# Wireframes

Low-fidelity, clickable wireframes for Kew v1. The live, editable version is the design canvas: https://claude.ai/artifact/6tkZR7eAVQicvsRxGwEESW (private; share it from the canvas's Share menu).

These files are the canvas source, kept here for history. They need the canvas runtime (`support.js`) to render, so open the canvas to view them.

| File | Screen |
| --- | --- |
| `Main.dc.html` | Today |
| `Pipeline.dc.html` | Pipeline board |
| `Company.dc.html` | Company record with copilot panel |
| `Diligence.dc.html` | Tabbed diligence workspace (financials, competition, files) |
| `Person.dc.html` | Person record with outreach log |
| `Fields.dc.html` | Settings: fields and pipeline stages |
| `Capture.dc.html` | Browser button popup |
| `canvas.json` | Canvas layout |

When the canvas changes, copy the updated files back here.
